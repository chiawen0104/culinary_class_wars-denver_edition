# Culinary Class Wars: Denver Edition

**English** | [中文](#黑白大廚丹佛版)

A simple Culinary Class Wars–style cooking battle, made for our Denver trip! One computer is all you need — no accounts, no server.

🔗 https://chiawen0104.github.io/culinary_class_wars-denver_edition/

## How It Works

1. **Player Setup**: Enter names (at least 4; tap "＋" to add). The 2 judges can be chosen or drawn at random; everyone else is drawn into the Black Team and the White Team.
2. **Grocery Battle**: The judges assign a main ingredient for each Round 1 match. Groceries for both rounds are bought together, by team. The team that spends less wins.
3. **Grocery Card Draw**: The winning team flips 1 of the 4 privilege cards, to be used in the team battle.
4. **Round 1: 1v1 Battle**: Players face off one-on-one, each cooking one 1–2 serving dish (main / appetizer / soup / dessert). No time limit.
5. **Blind Tasting**: Dishes are labeled only "Dish N (Black/White)", with no player names. Each judge scores separately; scores stay hidden until both judges have submitted.
6. **Round 1 Card Draw**: A 2:1 winner draws 1 card; a 3:0 winner draws 2. No draw on a tie.
7. **Round 2: Team Battle**: Each team cooks a 4-serving main course (rice / noodles / meat). No time limit, and privilege cards can be used at any time.
8. **Final Judging & Champion Reveal**: Both judges score, and the champion is crowned!

## Judging Criteria

| Criteria | Points | What judges look for |
|---|---|---|
| 1. Taste | 50% | Flavor, seasoning, texture and overall balance |
| 2. Creativity | 20% | Originality, clever ideas and distinctiveness |
| 3. Ingredient Utilization | 20% | Ingredient prep, cooking technique, sensible pairing |
| 4. Presentation | 10% | Visual appeal, neatness, plating |

## Privilege Cards

| Card | Effect | Rule |
|---|---|---|
| 🎁 Mystery Ingredient | The other team must add one extra ingredient prepared in advance by the judges | Must be used before the team battle starts |
| 🥩 Ingredient Steal | The other team names 3 non-essential ingredients; take 1 of them | Must be used before the team battle starts |
| 🤐 Mute Card | Pick one player on the other team: no talking for 5 minutes, hand signals only | Used during the team battle |
| 🧑‍🍳 Judge Helper | A judge helps wash, chop or prep for 5 minutes | The judge may not season, cook or make decisions |

Criteria, weights and cards can be edited under "⚙ 設定" (Settings) in the top-right corner.

## Saving Progress

- Every step is saved automatically in this computer's browser. Refreshing, closing the page, going offline or restarting won't lose anything.
- Only the "↺ 重來" (Reset) button clears it.
- Use the same computer, browser and URL, and don't use a private/incognito window.
- After the first visit, the page opens even without internet.

## Run Locally

Open `index.html` in a browser, or run this in the project folder:

```bash
python3 -m http.server 8123
```

Then open http://localhost:8123.

## Deploy to GitHub Pages

1. Push the code to the `main` branch on GitHub.
2. In the repo, go to **Settings → Pages**.
3. Set Source to "Deploy from a branch", choose `main` and `/ (root)`, then Save.

# 黑白大廚：丹佛版

[English](#culinary-class-wars-denver-edition) | **中文**

丹佛旅行限定的簡易黑白大廚料理對戰！只要一台電腦就能玩，不需要帳號、不需要伺服器。

🔗 https://chiawen0104.github.io/culinary_class_wars-denver_edition/

## 比賽流程

1. **參賽者設定**：輸入姓名（至少 4 人，按「＋」新增）。2 位評審可以指定，也可以隨機抽籤；其餘參賽者抽籤分成黑隊、白隊。
2. **採購戰**：評審指定第一輪個人戰每一場的主食材。兩輪的食材一起採買，以隊為單位，總花費較少的隊伍獲勝。
3. **採購戰抽卡**：採購勝隊從 4 張特權卡中翻開 1 張，在團體戰使用。
4. **第一輪：1 對 1 個人戰**：兩隊選手一對一 PK，每人煮一道 1–2 人份的菜／前菜／湯／甜點。不限時。
5. **個人戰盲測評分**：料理只標示「料理 N（黑隊／白隊）」，不顯示選手姓名。兩位評審各自評分，送出後分數會隱藏，兩人都送出才揭曉。
6. **個人戰抽卡**：2:1 勝隊抽 1 張、3:0 勝隊抽 2 張，平手不抽。
7. **第二輪：團體戰**：全隊合作完成 4 人份主食（飯／麵／肉）。不限時，比賽中隨時可以按「使用」特權卡。
8. **最終評分及冠軍揭曉**：兩位評審打分，公布黑白大廚總冠軍！

## 評審評分標準

| 評分項目 | 配分 | 評分重點 |
|---|---|---|
| 1. 味道 | 50% | 風味、調味、口感與整體平衡 |
| 2. 創意 | 20% | 原創性、料理巧思與特色 |
| 3. 食材運用 | 20% | 食材處理、烹飪技巧、搭配合理性 |
| 4. 擺盤 | 10 % | 視覺美感、整潔度、呈現方式 |

## 特權卡

| 卡片 | 效果 | 補充規則 |
|---|---|---|
| 🎁 神祕食材 | 對手的料理必須額外加入一樣評審事先準備的食材 | 必須於團體戰開始前使用 |
| 🥩 食材搶奪權 | 要求對手提出 3 種可被搶走的非必要食材，從中選擇 1 種奪取 | 必須在團體戰開始前使用 |
| 🤐 主廚禁言令 | 指定對手一位選手，禁止說話 5 分鐘，只能用手勢溝通 | 團體戰進行中使用 |
| 🧑‍🍳 評審幫手 | 指定一位評審協助洗菜、切菜或備料 5 分鐘 | 評審不可調味、烹飪或代替選手決策 |

評分項目、比例和特權卡內容，都可以在網頁右上角的「⚙ 設定」修改。

## 進度保存

- 每一步都會自動存在這台電腦的瀏覽器裡。重新整理、關掉網頁、斷網、重開機都不會遺失。
- 只有按右上角的「↺ 重來」才會清除。
- 請用同一台電腦、同一個瀏覽器、同一個網址，也不要用無痕視窗。
- 打開過一次之後，沒有網路也能再次打開網頁。

## 本機執行
